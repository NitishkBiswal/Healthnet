# Environment Variables Reference

| Variable | Default | Required | Description |
|---|---|---|---|
| APP_NAME | HealthNet | Yes | Name of the app |
| POSTGRES_URL | ... | Yes | Database connection string |
| REDIS_URL | ... | Yes | Cache connection string |
| KEYCLOAK_URL | ... | Yes | Auth provider URL |
| HAPI_FHIR_BASE_URL | ... | Yes | FHIR server base URL |
| SECRET_KEY | ... | Yes | Security key |
| CORS_ORIGINS | ... | Yes | Allowed CORS origins |
